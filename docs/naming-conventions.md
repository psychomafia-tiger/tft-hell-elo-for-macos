# Naming Conventions — TFT Hell Elo

**Status**: Locked 2026-04-25 (Wave 5a rename)
**Supersedes**: previous `asia.lab3.tftmac` prefix from Phase 1 Wave 1-4

---

## Why the rename

Wave 5 pivot (post-dogfood, 3 issues landed) triggered owner change: `asia.lab3` → `psychomafia`. Owner GitHub handle is `psychomafia-tiger`; bundle prefix `io.psychomafia` matches. Display name "TFT Hell Elo" captures product positioning for TFT players grinding hell elo (Diamond → Master → GM tier range, where tactical depth matters most).

## Name layer map

| Layer | Value | Why |
|-------|-------|-----|
| **Bundle ID** | `io.psychomafia.tfthellelo` | LaunchServices unique ID, GitHub Releases artifact name |
| **Display name** | `TFT Hell Elo` | Shown in Finder, Dock, menu bar, About dialog |
| **Menu bar label** | `TFT Hell Elo` | `MenuBarExtra` first arg, accessibility label |
| **Xcode target name** | `TFTMac` | **Retained** — rename would break XCUITest hardcoded references + DerivedData paths |
| **Swift @main struct** | `TFTMacApp` | Retained — type name change cascades across 5+ test files and `@testable import TFTMac` |
| **Scheme name** | `TFTMac` | Retained — matches target name |
| **Product executable** | `TFTMac.app` | Retained — target name drives this |
| **OSLog subsystem** | `io.psychomafia.tfthellelo` | Matches bundle ID for Instruments filtering |

## Rule

**User-facing** strings (display name, menu label, About dialog, hotkey conflict log) = "TFT Hell Elo".
**Code identifiers** (target, scheme, type names) = "TFTMac" (legacy retained).

## Regression guards

- `BundleIdentifierRegressionTest.swift` asserts `Bundle.main.bundleIdentifier == "io.psychomafia.tfthellelo"` — catches accidental revert of project.yml
- HeaderBar shows "TFT Hell Elo" literal (unit test can extend CompCardV2Tests to assert this if needed post Wave 5c)
- Info.plist `CFBundleDisplayName` = "TFT Hell Elo" (sync with project.yml, regenerated by `xcodegen generate`)

## Migration note for existing 10 testers

First-time installs after this rename land a **second app** next to old `asia.lab3.tftmac`. LaunchServices treats different bundle IDs as distinct apps. Steps for dogfood testers:

1. Quit old `TFT Mac` via menu bar
2. `rm -rf /Applications/TFTMac.app` (or from wherever installed)
3. Install new `.dmg` from GitHub Releases
4. Re-grant Accessibility permission (System Settings → Privacy → Accessibility → add new TFT Hell Elo binary)

Force reinstall acceptable for 10-user dogfood scope; no auto-migration script in v0.1.

## Rollback

If rename causes unforeseen breakage, revert commit `feat(app): Wave 5a rename ...` restores `asia.lab3.tftmac` across project.yml + Info.plist + SignpostChannels + HeaderBar + TFTMacApp in one atomic step.
